# Orbit Sandbox

An n-body gravity simulator. Drag and release to slingshot planets around a star; bodies attract each other, leave orbital trails, and merge on collision (conserving momentum).

- Drag & release — launch a planet (drag back like a slingshot)
- **1/2/3** — planet size · **G** — toggle the star · **P** — pause
- **C** — clear planets · **S** — save the canvas as PNG

Single HTML file, softened pairwise gravity with substepping. Open `index.html` to play.
