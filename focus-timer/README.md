# Focus Timer

A pomodoro timer with a glowing progress ring.

- Focus / short break / long break (long break after every 4th focus)
- **SPACE** or button to start/pause, skip, reset; durations are editable
- WebAudio chime on phase end, countdown in the tab title
- Daily completed-session count persists in `localStorage`

Single HTML file. Open `index.html` to use.
