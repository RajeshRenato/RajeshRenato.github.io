# TIME OVERLAP

A timezone meeting planner: add up to 8 cities and see a 24-hour grid of everyone's local time for each hour of *your* day — colored by working hours (9–18), stretch hours, and sleep. Columns where **everyone** is in core working hours get a green outline. Uses the browser's `Intl` timezone database, so DST is always correct with zero embedded data. Live clocks per city; selections persist.

Single HTML file — open `index.html` to use.
