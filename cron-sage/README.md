# CRON SAGE

Type a 5-field cron expression, get a plain-English description plus the **next 6 run times** (with relative countdowns). Supports `*`, steps (`*/n`), ranges (`a-b`, with steps), lists, and month/weekday names — including the classic cron quirk where restricted day-of-month OR weekday matches. Validation pinpoints the broken field; presets included.

Single HTML file — open `index.html` to use.
