# ARCADE TYCOON

An idle/incremental game: build a synthwave arcade empire. Click for coins, buy five generator tiers (arcade cabinets → space elevator) with 1.15× compounding costs, upgrade your click power, and earn **offline progress** (capped at 8 hours) while the tab is closed. Progress autosaves to `localStorage`.

Single HTML file — open `index.html` to play.
