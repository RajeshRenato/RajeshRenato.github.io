# CSV Viewer

Paste CSV/TSV or open a file and get a clean, sortable table — fully offline.

- Proper CSV parser: quoted fields, escaped quotes, commas and newlines inside quotes
- Delimiter auto-detection (`,` `;` tab `|`), first-row-header toggle
- Click headers to sort (numeric-aware), live row filter
- Export the current view as JSON (copy or download); renders up to 2,000 rows

Single HTML file. Open `index.html` to use.
