# PROFILE BANNER

Generate an **animated SVG banner** for your GitHub profile README — glow pulse, twinkling stars, perspective grid, blinking cursor — all SMIL animations that GitHub actually renders.

- 4 themes (synthwave, ocean, terminal, ember), toggleable grid/stars/cursor
- Star positions are deterministic per name, so your banner is stable
- Input is XML-escaped; download `.svg`, copy the SVG, or copy the README markdown
- No accounts, no tracking, nothing leaves the page

Drop `banner.svg` into your `username/username` repo and add `![banner](banner.svg)` to the README.

Single HTML file — open `index.html` to use.
