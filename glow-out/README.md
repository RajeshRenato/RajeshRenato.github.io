# GLOW OUT

Lights-out on a neon grid: pressing a tile flips it and its four neighbours. Switch everything off.

**Always solvable, with honest hints.** Boards are built by pressing random tiles on a dark grid, so the press set is a known solution. Presses commute and cancel in pairs, so the game tracks that set exactly as you play — the hint button always points at a tile that is genuinely part of a solution from the current position.

- Endless levels: grids grow 3×3 → 7×7 with more scrambling presses
- Par = scramble size; land exactly on par for a **PERFECT**
- Hint, reset, reroll
- The seed lives in the URL — share a link, race a friend on the identical board

Single HTML file — open `index.html` to play.
