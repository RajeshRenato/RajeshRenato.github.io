# BEAT GRID

A 16-step, 6-track drum machine where every sound is synthesized live with WebAudio — kick, snare, closed/open hats, clap, and bass, no samples. Lookahead scheduling keeps timing tight; tempo 60–180 BPM.

The entire pattern is encoded in the URL hash — **copy the link, share the beat**. SPACE toggles play; random generates a sensible four-on-the-floor starting groove.

Single HTML file — open `index.html` to jam.
