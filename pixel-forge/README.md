# PIXEL FORGE

A tiny pixel art editor: 16×16 or 32×32 canvas with pencil, eraser, flood fill, and eyedropper tools, a 16-color neon palette plus custom color picker, undo (40 levels), transparent-checker background, autosave to `localStorage`, and **PNG export** at 16× scale.

Single HTML file — open `index.html` to draw.
