# STACK TOWER

A one-button timing game: a block slides back and forth — drop it on the stack. The overhang gets sliced off and tumbles away, so every miss makes the next landing harder. Perfect drops (±5px) snap into place with a glow and keep your full width. Speed ramps with height; camera follows the tower; best height in `localStorage`. Great on mobile.

Single HTML file — open `index.html` to play.
