# Regex Playground

Live regular-expression tester — everything runs in the browser, nothing leaves the page.

- Pattern + flags with instant validation and match count
- Matches highlighted inline (zero-width matches shown as ∅)
- Match list with numbered and named capture groups
- Replace preview with `$1` / `$<name>` support
- Built-in cheatsheet; session persists in `localStorage`

Single HTML file. Open `index.html` to use.
