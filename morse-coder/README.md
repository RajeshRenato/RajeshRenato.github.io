# MORSE CODER

Two-way live morse translator (text ↔ morse, letters/digits/punctuation), with WebAudio playback at 8–30 WPM using proper PARIS timing (1/3 unit tones, 3/7 unit gaps) and an optional full-screen flash. Includes a trainer: a random character plays and displays, you type the answer, streaks tracked with a best in `localStorage`.

Single HTML file — open `index.html` to use.
