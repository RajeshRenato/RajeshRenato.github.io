# ROCK BLASTER

Asteroids-style vector shooter: thrust-and-drift ship with screen wrap, jagged procedural rocks that split twice, respawn invincibility blink, levels, lives, and particles.

- ←→ rotate · ↑ thrust · SPACE fire (max 5 shots) · R restart
- Best score persists in `localStorage`

Single HTML file. Open `index.html` to play.
