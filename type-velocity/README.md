# Type Velocity

A 30/60-second typing speed test.

- Just start typing — the timer starts on the first keystroke
- Per-character correctness coloring, word-level error marks
- Live WPM, final accuracy, words completed; personal bests per mode in `localStorage`
- **TAB** restarts instantly

WPM is standard: correct characters ÷ 5 ÷ minutes. Single HTML file, open `index.html` to play.
