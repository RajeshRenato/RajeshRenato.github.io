# Markdown Pad

Split-pane live markdown editor with a hand-rolled ~160-line parser — no libraries.

- Headings, bold/italic/strikethrough, inline code, fenced code blocks, links, images, lists, blockquotes, horizontal rules
- Autosaves to `localStorage`, word/char count, download as `.md`, copy rendered HTML
- Input is HTML-escaped before parsing

Single HTML file. Open `index.html` to use.
