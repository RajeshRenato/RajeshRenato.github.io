# REFLEX LAB

A three-test reaction battery with ratings and personal bests (`localStorage`):

- **Reaction** — wait for green, click fast; 5 rounds, early clicks rejected
- **Aim** — pop 10 targets as they appear; tracks avg time per target and misses
- **Choice** — press the arrow key shown; wrong keys add a 250ms penalty

Single HTML file — open `index.html` to test yourself.
