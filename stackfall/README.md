# STACKFALL

Falling-tetromino puzzle: 7-bag randomizer, ghost piece, hold, next preview, wall kicks, soft/hard drop, line-clear scoring (100/300/500/800 × level), and speed that ramps every 10 lines.

- ←→ move · ↑/X rotate · Z counter-rotate · ↓ soft drop · SPACE hard drop · C hold · P pause
- Best score persists in `localStorage`

Single HTML file. Open `index.html` to play.
