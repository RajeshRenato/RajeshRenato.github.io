# SUDOKU

Full sudoku with a real generator: a solved grid is produced by randomized backtracking, then clues are removed only while the puzzle keeps **exactly one solution** (verified by a counting solver). Easy/medium/hard (40/32/27 clues), row/column/box conflict highlighting, peer highlighting, mistake counter, timer, keyboard + number-pad input.

Single HTML file — open `index.html` to play.
