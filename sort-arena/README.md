# SORT ARENA

Race two sorting algorithms head-to-head on the same shuffled data: bubble, insertion, selection, merge, quick, and heap sort — each implemented as a generator yielding one comparison/step at a time, so both panels advance in lockstep and the op counters tell the real story. Adjustable array size and speed; sorted bars turn green, winner gets the trophy.

Single HTML file — open `index.html` to race.
