# GRID DEFENSE

A micro tower defense. Creeps snake along the path; build blasters (fast, cheap) and snipers (slow, long-range) on empty cells to stop them. Towers auto-target the front-most creep in range. Waves scale in HP (+22%/wave), count, and speed. Kills pay bounties; leaks cost lives. Best wave persists in `localStorage`.

Single HTML file — open `index.html` to play.
