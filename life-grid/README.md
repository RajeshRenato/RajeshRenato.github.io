# Life Grid

Conway's Game of Life on a 96×60 toroidal grid (edges wrap). Draw cells with the mouse, then watch them evolve — recently died cells leave a fading blue glow.

- Play/pause (**SPACE**), single step, randomize, clear, speed slider
- Presets: glider, pulsar, Gosper glider gun
- Generation and population counters

Single HTML file. Open `index.html` to run.
